# karyana-store-system
Mera pehla Python OOP project - Shop ka bill system
## Features
- Customer ka bill banana
- Stock check karna (agar stock kam ho to mana kar dega)
- Price user khud input karta hai, koi fix price nahi hai
- Jo bhi price ho, uska automatic 10% discount lag jata hai
- Har customer ka bill .txt file me save karna

## Kaise Chalayein
1. `main.py` ko run karein
2. Customer ka naam likhein
3. Cheez, qty aur price likhein
4. `ok` likh kar bill khatam karein

## Technologies
- Python
- OOP (Class - Bill)
